# Лабораторная работа № 2

Сухарев Фёдор Дмитриевич, группа 527, номер 23. По формуле методички это вариант 12: маршрут доставки по 20 адресам с ограничением общего времени.

## Запуск

Из папки `lab2`:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Программа делает по 20 запусков трёх настроек генетического алгоритма и простой эвристики. Все случайные числа имеют фиксированные seed. Параметры находятся в [config.json](config.json), адреса — в [data/points.csv](data/points.csv). Для повторного создания адресов можно запустить `python generate_data.py`.

Проверка основных свойств:

```powershell
python -m unittest discover -s . -p "test_*.py"
```

## Файлы

- [main.py](main.py) — алгоритм, сравнение методов и построение графиков.
- [report.md](report.md) — постановка задачи, операторы, результаты и выводы.
- `results/runs.csv` — итог каждого запуска: seed, длина, время, маршрут и число оценок.
- `results/history.csv` — сходимость по серии запусков через каждые 100 оценок.
- `results/summary.json` — сводная статистика.
- `results/best_route.csv`, `results/best_route.json` — лучший найденный маршрут.
- `results/best_route.png`, `results/convergence.png` — карта и график сходимости.

Генетические операторы написаны самостоятельно. Сторонняя библиотека Matplotlib используется только для графиков.
